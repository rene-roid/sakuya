# Sakuya 1.4.0

### Added
- **Discover** — a recommendation feed built from the tags on media you like, watch and linger on. Off by default; turn it on in Settings → Behaviour.
- **I'm feeling lucky** — one pick from the far end of the surprise range, opened straight in the viewer, with the rest of the shuffle waiting behind it if you keep paging.
- **Surprise slider** — mixes random picks into the Discover feed, from "only things I already like" through to pure chance.
- **Dwell time** — images and GIFs now record how long they stay open, the still-image counterpart to watched time on video. Sub-second glances and time spent in a background tab don't count.
- **Reason badges** — every Discover card credits the tag that earned it a spot, marking tags reached through related content differently from ones you engaged with directly.
- **Home-folder data storage** — data now lives in `~/.sakuya` by default instead of the install folder. Move existing data between locations from Settings → System, or point `SAKUYA_DATA_DIR` elsewhere yourself; `setup.sh`/`setup.bat` ask where to keep it up front.
- **Library reordering** — drag libraries into the order you want from Settings → Libraries; it sticks across restarts.
- **Inline library rename** — rename a library from the Libraries tab without touching the folder on disk.
- **Update notifications** — a dismissible toast nags once a day when a newer GitHub release is out.

### Improved
- Discover mixes images and videos behind a type filter, and downweights media you have already seen instead of hiding it.
- Related tags pull in adjacent content by affinity — how much of a tag's use sits next to tags you like — rather than by raw co-occurrence, which only ever resurfaced whatever was most common library-wide.
- Engagement tracking runs whether or not Discover is enabled, so the feed is already populated the first time you switch it on.
- Scrollbars are thinner, overlay-style, and themed for both Firefox and WebKit.

### Fixed
- Versioned migrations recorded the wrong baseline for databases created before that mechanism landed, so newly added columns could be skipped instead of applied.

### Other
- Server tests run with `bun test --isolate` (`bun run test`) — each suite boots its own server and database, so they can't share a process.
