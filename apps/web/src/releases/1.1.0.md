# Sakuya 1.1.0

### Added
- **Scan All Libraries** button in the Jobs menu to kick off a scan for every library at once, with toast notifications for success or failure.
- **Detect GIFs as Videos** setting to classify GIFs as videos instead of images, with a reclassification job for existing files.
- **Ugoira → GIF conversion** for Pixiv downloads — ugoira zips are automatically converted to GIFs during scans and gallery-dl downloads.
- **Gallery-dl Console** — an interactive console for gallery-dl sessions with live output, plus input and stop controls.
- **Redo download** — requeue a completed download straight from the Downloader page.
- **Duplicates** — scan for and review duplicate media, then batch-delete the ones you don't need.
- **Rename and delete** files directly from the media viewer, with confirmation dialogs.
- **Docker support** — Dockerfiles, docker-compose, and an nginx config for containerized deployments.
- **Reveal in File Explorer** button in the media viewer.

### Improved
- The Downloader now handles batch events in real time and supports deleting cookie files.
- Library rescans automatically trigger after a downloader batch finishes, cleaning up missing files and thumbnails.
- The tag sidebar was split into per-category queries for better performance.
- Cross-platform scripts for pulling updates and dependencies.
