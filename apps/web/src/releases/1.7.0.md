# Sakuya 1.7.0

### New
- **Desktop app for Windows and Linux.** Each release now ships a Windows installer (`.exe`) and a Linux AppImage on its GitHub page. Both bundle everything Sakuya needs, so there's no Bun to install and no terminal to keep open, and they keep their config and data in `~/.sakuya`. Closing the window leaves Sakuya running in the tray. **Start at Login** in the tray menu turns autostart on or off.
- **Liquid Glass style.** A frosted look with pill navigation and a dashboard banner, next to the original one. Sakuya asks once which you prefer, and Settings → Appearance switches between them any time.
- **Better on phones.** Navigation moves to a bottom dock on small screens, the top bars slide away while you scroll down, and libraries and tags open from a drawer.

### Fixed
- **Scans are more careful with your library.** A folder that can't be read (permissions, a disk error, an unmounted drive) keeps its media instead of losing it, and a scan no longer adds media back for a library removed while it ran. Folders symlinked inside another folder are now indexed.
- **Detaching a folder no longer removes media another folder in the library still covers**, along with its tags, likes and boards.
- **Jobs no longer get stuck or run twice.** Two scans of one library never run at once, a job that failed early no longer blocks every later job of its kind, and folders left "scanning" by a crash reset when the server starts.
- **Video transcodes:** two jobs no longer encode the same video at once, which could serve a corrupted file. "Check all videos" no longer re-encodes videos that are already done, and partial files left by a crash are cleaned up after a day.
- **Viewer:** it stays on the right item when the list changes, keeps a video's resume point, saves tags, renames and likes to the item they were made on, and leaves keys typed into text fields alone.
- **Tags:** filtering by the same tag twice (or `Silver Hair` and `silver_hair`) now finds matches, `_` in a tag search is no longer a wildcard, and suggestions only use the tag you're currently typing.
- **Renames:** changing only the case of a name works on Windows and macOS, and renaming onto a file another item owns is refused.
- **Security:** library covers must be images and are served sandboxed, and cookie uploads can no longer write outside the cookies folder.
- A rejected settings change no longer half-saves, adding a deleted item to a board no longer fails the whole add, a full disk while downloading the tagger model or gallery-dl no longer crashes the server, and gallery-dl extra arguments keep their quotes.

### Faster
- Media lists, tag autocomplete and rescans of unchanged libraries are quicker, and grid thumbnails load as you scroll.
