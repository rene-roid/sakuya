# Sakuya 1.5.0

### Breaking
- **The server now listens on `127.0.0.1` by default.** It used to accept connections from anywhere on the network while login stayed off unless you enabled it — which meant starting Sakuya published your whole library, and the "reveal in file manager" action, to everyone on the LAN. To reach it from another machine, set `SAKUYA_HOST=0.0.0.0`, ideally together with `AUTH_ENABLED=true`. **Docker users need to do nothing**: the image already binds all interfaces, since a container must.
- **Search matches from the start of a word instead of anywhere inside it.** Searching `saku` still finds `sakuya_izayoi.png`, but `aku` no longer does, and `0101` no longer finds `IMG_20240101_123.jpg`. This is what makes search use an index; whole words and prefixes behave as before, and searches got between 7x and 240x faster.
- **Everyone logged in gets signed out once.** The login cookie used to be your password stored verbatim; it is now a signed, expiring session token. Log in again and it won't happen twice. Changing `AUTH_SECRET` now signs out every session, which it previously couldn't do.

### Added
- **Multi-select and bulk actions** — click to toggle, shift-click for a range, ctrl/cmd-click to enter select mode, Ctrl+A for the loaded page, Esc to leave. "Select all N" resolves server-side, so a selection can cover pages the grid never rendered. Bulk tags, board membership, rename, like, delete, AI re-tag, thumbnail regeneration and copying paths, each behind a confirmation that lists what will change file by file rather than showing a bare count.
- **Bulk rename** — a token pattern (`{name}`, `{ext}`, `{n:3}`, `{date}`) or find/replace with optional regex, previewed live. Collisions are detected before anything touches disk.
- **History retention** — the cleanup job now prunes finished jobs and the logs of finished downloads older than two weeks, and reports what it removed. These two tables previously grew forever.

### Improved
- **Small media fills the viewer.** A 480x360 video or a small GIF used to sit at its native size in the middle of the window; it now scales up to fit, without the stretched control bar that the obvious fix causes on video.
- **Similar images open ~13x faster.** Finding visually similar media used to compare against every image in the library on each viewer open. Perceptual hashes are now indexed, so it compares against a few hundred candidates instead of tens of thousands.
- **Discover is faster to scroll.** The taste profile is computed once and reused rather than rebuilt from scratch every 60 items, and still updates immediately when you like something or change tags.
- **Bulk actions are much faster on large selections**, and deleting a batch is now atomic — it can no longer half-apply.
- Paging through a grid no longer recounts the whole filtered library on every page.
- The Settings → System version is read from one place instead of being hardcoded, so it stops disagreeing with the release you're actually running.

### Fixed
- Settings → System reported version `0.1.0` regardless of the installed version.
- The cleanup job's tag recount bound one parameter per tag for a condition that did nothing, and was on course to hit SQLite's parameter limit as your tag vocabulary grew.
- Tag and job status polling no longer loads every matching row just to count them.

### Other
- Added a container healthcheck, and CI running lint, typecheck, tests and the web build.
- ESLint and Prettier configs, with the lint baseline clean.
- New tests cover search, similar-image matching, login, cleanup retention, pagination and schema drift.
