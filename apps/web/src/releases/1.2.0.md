# Sakuya 1.2.0

### Added
- **Password protection** — gate the whole app behind a password, with cookie-based login and logout.
- **User boards** — build collections of media, browse them on their own page, and add or remove items straight from the viewer.
- **Saved searches** — save a set of Explore filters under a name and replay it later from the sidebar; saving under an existing name overwrites it.
- **Video transcoding** — browser-incompatible codecs and containers are converted to mp4 by a background job and served automatically.
- **View tracking** — media now records view counts and watched time, shown in the viewer's metadata.
- **Sort by file size**, largest first.
- **Mobile support** — responsive navbar, viewer, sidebar, dialogs, and grids across the app.

### Improved
- The Explore filter bar keeps multiple free-text terms as removable chips and ANDs them together, with a "Clear all" button.
- Tag completion is explicit now: Tab or arrow-select completes a suggestion, Enter stays a plain search, and free text can be mixed with tags.
- Database migrations are versioned via `PRAGMA user_version` — only pending ones run, and failures crash loudly instead of being swallowed.
- The Board browse page was renamed to **Explore** to stop it clashing with the new Boards feature.

### Other
- The project is now called **Sakuya** (formerly tbge), with a rewritten README, setup docs, and an MIT license.
