# Sakuya 1.8.1

### New
- **Change the password from Settings.** The new **Security** section in Settings sets, changes or turns off the login password. Changing it or turning login off asks for the current password first, even when you're already signed in, and signs every other device out.
- **Forgot the password? Edit the config file.** The password is `auth.secret` in `sakuya.config.json` (`~/.sakuya/sakuya.config.json` for the desktop app). A saved edit now applies within a few seconds, with no restart. Settings → Security shows where the file is.

### Docker
- `docker-compose.yml` now mounts `sakuya.config.json` writable so Settings can save a new password. Run `docker compose up -d` to recreate the container with it. Set `read_only: true` on that volume if you'd rather change the password only on the host. A password set with `SAKUYA_AUTH_SECRET` still wins, and Settings says so.
